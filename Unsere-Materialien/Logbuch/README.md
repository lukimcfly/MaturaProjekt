## Aufbau (neues Logbuch)

Querformat, Seitenzahlen in der Fusszeile, Kopfzeile der Tabelle wiederholt sich
auf jeder Seite. Eine Zeile pro Arbeitstag (Nachträge beim Datum vermerkt):

| Spalte | Inhalt |
|---|---|
| Datum | Format TT/MM/JJ |
| Dauer / Wer | Zeitaufwand und Beteiligte (ohne Namen) |
| Arbeitsschritte | Was wurde gemacht |
| Ergebnisse | Was ist dabei herausgekommen, Probleme und Lösungen |
| Reflexionen | Was haben wir daraus gelernt (selbst schreiben, nicht von der KI) |
| KI-Nutzung | Tool + Version, wofür, Verweis auf Prompt-Nummer, Art der Übernahme |

Danach folgt der **Anhang «KI-Nachweis»**: jeder Prompt im Wortlaut mit Nummer (K1, K2 …),
Datum, Tool und Art der Übernahme. Die Seitenzahlen von Logbuch und Anhang kommen ins
Raster «Verwendung von KI» im schriftlichen Kommentar.
